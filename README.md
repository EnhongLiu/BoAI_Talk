# Bovi-Talk: Conversational AI for Dairy Science

🚀 **Bovi-Talk** is an interactive AI-powered system designed to help users interact with dairy science models using natural language. It leverages **large language models (LLMs)** and **graph-based workflows** to provide insights into **milk yield prediction, visualization, and decision support**.

## 📌 Features

- **Conversational AI**: Use natural language to query and interact with statistical models.
- **MilkBot Integration**: Extracts key parameters and generates milk yield predictions.
- **Automated Visualizations**: Converts extracted insights into intuitive graphs.
- **LLM-Powered Decision Making**: Dynamically selects the appropriate tool for user queries.
- **Multi-Agent Workflow**: Implements a structured decision-making process using `langgraph`.

## 🛠️ Tech Stack

- **LLMs**: `Databricks LangChain`, `Google Generative AI`
- **Graph-Based AI**: `LangGraph`
- **Machine Learning & Bayesian Modeling**: `PyMC`, `Scipy`
- **Data Processing**: `Pandas`, `NumPy`
- **Visualization**: `Matplotlib`
- **Cloud & Vector Storage**: `Databricks Embeddings`
- **LLM Tools & Agents**: `LangChain Tools`, `ToolNode`
